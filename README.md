# Lista de Exercícios – Engenharia de Software II

## Descrição

Este repositório contém a resolução da Lista de Exercícios da disciplina **SIN391 – Engenharia de Software II**.

O material aborda conceitos fundamentais de Engenharia de Software, incluindo processos de desenvolvimento e modelos de ciclo de vida de software.

## Conteúdo

Os exercícios contemplam temas como:

- Conceito de processo de desenvolvimento de software;
- Modelos de processo de software;
- Modelo Cascata;
- Desenvolvimento Incremental;
- Modelo Espiral;
- Vantagens e desvantagens dos modelos de processo;
- Comparação entre diferentes abordagens de desenvolvimento;
- Aplicação dos modelos em projetos de software.

## Objetivo

Compreender as características, vantagens, limitações e aplicações dos principais modelos de processo de software utilizados no desenvolvimento de sistemas.
